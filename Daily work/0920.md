### 2.5 Data Types

1. Number
> 1. The number type represents both integer and floating point numbers.
>> There are many operations for numbers, such as multiplication * , division / , addition +, subtraction - , and so on.
> 2. Besides regular numbers, there are so-called “special numeric values” which also belong to this datatype: Infinity, -Infinity and NaN.
>> 1. Infinity : alert(1/0) ; or alert(infinity)
>>>represents the mathematical Infinity
>> 2. NaN :represents a computational error. It is a result of an incorrect or an undefined mathematical operation, for instance. e.g. alert("not a number"/2);//Nan 
>>> NaN is sticky. Any further operation on NaN returns NaN.

2. BigInt
> 1. Number Type cannot precisely represent a number larger than $2^{53}$-1 or smaller than -$2^{53}$ -1 (not all numbers fit into a fixed 64-bit storage).
> 2. BigInt can represent any number :
>> const BigInt = any number 

3. String
> 1. A string in JavaScript must be surrounded by quotes : '' or "" or ``
>> 1. '' or "" are simple quotes .
>> 2.  `` (the button beneath Esc) is abled to embed variables and expressions into a string by wrapping them in ${...} .
>>> e.g. alert( "the result is `${1+2}`) // the result is 3 ; let name = John alert (Hello `${name}`) //Hello ,John

4. Boolean
> Boolean is a logical type , only contains two values : true or false
>> 1. Boolean  is commonly used to store yes/no values: true means “yes, correct”, and false means “no, incorrect”. 
>> 2. Boolean can also be used as a result in comparsions .
>>> e.g. let number=4>1 ,alert (number) // true

5. Null
> 1. Null forms a separate type of its own which contains only the null value.
> 2. Null is just a special value which represents “nothing”, “empty” or “value unknown”.

6. Undefined
> 1. Undefined is also a separate type of its own.
> 2. The meaning of undefined is “value is not assigned’.If a variable is declared, but not assigned, then its value is undefined .
>> e.g. let name = undefined； alert（name） //undefined

7.  Objects
>  objects are used to store collections of data and more complex entities.

8. Symbols 
>Symbol type is used to create unique identifiers for objects.

### 2.6 Interaction : alert,prompt & confirm

1. Alert
> - alert("message");
> - alert will appear a message , and wait for user to press ok.
>> The popup window with the message is called "modal", which means that users cannot interact with the rest of the page (such as clicking other buttons) until they have interacted with the window—in this case, until they click the "OK" button.

2. Prompt
> - result = prompt(title, [default]);
> - Prompt accept two parameters , which will show a modal window with message , as well as input box and yes/no buttons.
>> - title is the text showed to user
>> - default is an optional parameter to specify the initial value of the box.
>>>[...] means that it is optional , not necessary.
> User can input some contents in the input box , and the contents will be obtained in the result ; or user can cancel or press Esc , then the result will be null.
> - e.g. et age = prompt('How old are you?', 100);
>alert(`You are ${age} years old!`); // You are 100 years old!

3. Confirm
> - result = confirm(question)
> - Confirm shows a modal window with question and YES/NO buttons.
> - e.g. et isBoss = confirm("Are you the boss?");
> alert( isBoss ); // If the YES button is pressed , it will apear "true"

### 2.7 Type Conversions

1. To String
> - alert(value) makes the string of the value , and then shows the value.
> - String(value) function can also be used to convert a value to a string.
>> - e.g. let value = true; alert(typeof value); // boolean
>> - value = String(value); // now value is a string "true" alert(typeof value); // string

2. To Number
> 1. Numeric conversion happens in mathematical functions and expressions automatically.
>> e.g. alert("6"/"2"); //3 ,strings are converted to numbers.
> 2. Number(value) can be used to convert value to a number type
>> - e.g. let str = "123"; alert(typeof str);//string
>> - let num = Number(str);//convert to number type // alert(typeof num);//number
> 3. Explicit conversion is usually required when we read a value from a string-based source like a text form but expect a number to be entered.
>> - let value = number ; does not make the value a number type , instead , the type of the value is still string .
>> - If the string is not a valid number , the result is NaN . 
>> - e.g. let age = Number("an arbitrary string instead of a number");alert(age); // NaN, conversion failed
> 4. Numeric conversion rules
>> - undefined → NaN
>> - null → 0
>> - true/false → 1/0
>> - strings → Whitespaces from the start and end are removed. If the remaining string is empty, the result is 0. Otherwise, the number is “read” from the string. An error gives NaN
>>> - alert("  123  "); //123// 
>>> - alert("  123z "); //NaN//
3. To Boolean
> - Values that are intuitively “empty”, like 0, an empty string, null, undefined, and NaN, become false.
> - Other values become true.
>> - e.g. alert(Boolean(0));//false
>> - alert(Boolean(1));//true
>> - alert(Boolean(""));//false
