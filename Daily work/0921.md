### 2.8 Operators

1. Terms: “unary”, “binary”, “operand”
>  addition "+" , substracion "-" , multiplication "*" , division "/" , remainder " %" , exponentation "**" 
> 1.  Operand  is what operators are applied to. 
>> - An operator is unary if it has a single operand. e.g. the negation "-" reverses the sign of a number.
>> - An operator is binary if it has two operands.\
>> - There are two different operators here: the unary negation (single operand: reverses the sign) and the binary subtraction (two operands: subtracts).

2. Remainder %
> 1. The result of a % b is the remainder of the integer division of a by b.
>> e.g. alert( 5% 2 ) // 1 is a remainder of 5 divided by 2

3. Exponentation
> 1. For anatural number b, the result of a ** b is a multiplied by itself b times.
>> - e.g. alert( 2** 4); //16 (2 * 2 * 2 * 2)
>> - e.g. alert( 8** (1/3)); //2 (power of 1/3 )

9. Increment/decrement
> - Increment " ++ " increases a variable by 1.
>> ```javascript
>> let counter = 2 ;
>> counter++ ; //
>> alert(counter) ; //3
> - Decrement " -- " decreases a variable by 1:

> 1. The operators ++ and -- canbe placed either before or after a variable.
>> 1. When the operator goes after the variable, it is in “postfix form’: counter++. 
>> 2. The “prefix form” is when the operator goes before the variable: ++counter .
>>> ```javascript 
>>> let counter = 1 ;
>>> let a = ++counter ;
>>> alert(a) ; //2
>>>
>>> let counter = 1 ;
>>> let a = counter++ ;
>>> alert(a) ; //1
>> 3. But if the result of increment/decrement is not used, there is no difference in which form to use:
>>> ```javascript
>>> let counter = 1 ;
>>> counter++ ;
>>> ++counter ;
>>> alert(counter) ; //2 

> 2. Incrementidecrement among other operators
>> - The operators ++/-- can be used inside expressions as well. 
>>> ```javascript
>>> let counter = 1 ;
>>> alert( 2 * counter++ ) ; //2
>>>
>>> let counter = 1 ;
>>> alert( 2 * ++counter ) ; //4
>> - Their precedence is higher than most other arithmetical operations.
