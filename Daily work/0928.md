### 2.14 The 'Switch' Statement

1. The Syntax
>The switch has one or more case blocks and an optional default.
>```javascript
> switch(x){
> case 'value1' : //if(x === 'value1')
> ...
> break;
> case 'value2' : //if(x === 'value2')
> break;
> default:
> break
> }

> - EXAMPLE:
> ```javascript
> let a = '1';
> let b = 0;
> switch(+a){
>    case b+1:
>    alert('this run');
>    break;
> default:
>    alert('this does not run');
> }

2. Grouping of 'Case'
> ```javascript
> let a = 3;
> switch(a){
>    case 4:
>    break;
>    case 3:
>    case 5:
>    alert(wrong);
>    break;
>    default:
>    alert('the result is strange');
>    }
> //Now both 3 and 5 show the same message.

3. Type Matters
>  The equality check is always strict. The values must be of the same type to match.

### 2.15 Functions

1. Function Declaration
> ```javascript
> function name(parameter1,parameter2,...parameterN){
> ...body...
> }

> New function can be called by its name: name().
> ```javascript
> function showMessage(){
> alert('hello');
> }
> showMessage();
> showMessage();
>//The call showMessage() executes the code of the function. Here we will see the message two times.

2. Local Variables
> A variable declared inside a function is only visible inside that function.
 ```javascript
 function showMessage(){
    let message = 'hello, I am Rafael.'//Local Variable
    alert(message);
 }
 showMessage();//hello, I am Rafael
 alert(message);//error
 ```
3. Outer Variables
>1. A function can access an outer variable as well.
```javascript
let userName = 'Bahram';
function showMessage(){
    let message = 'hello,' + userName ;
    alert(message);
}
showMaessage();//hello,Bahram
```
>2. The function has full access to the outer variable. It can modify it as well.
```javascript
let userName = 'Bahram';
function showMessage(){
    userName = 'Rafael';
    let message = 'hello,' + userName ;
    alert(message);
}
alert(userName);//Bahram before the function call
showMaessage();//hello,Bahram
alert(userName);//Rafael the value was modified by the function
```
>3. If a same-named variable is declared inside the function then it shadows the outer one, which is,  the function will use the local variable instead of the outer one. The outer one is ignored:
```javascript
let userName = 'John';
function showMessage() {
  let userName = "Bob"; // declare a local variable

  let message = 'Hello, ' + userName; // Bob
  alert(message);
}// the function will create and use its own userName
showMessage();
alert( userName ); // John, unchanged, the function did not access the outer variable
```

4. Parameters
> - Using parameters can pass arbitrary data to functions .
```javascript
function showMessage(from,text){//parameters: from, text
    alert(from + ':' + text)
}
showMessage('Rafael','Hello');//Rafael： Hello
showMessage('Bahram','What’s up');//Bahram: What's up
```

> - When a value is passed as a function parameter, it’s also called an argument.
>>> - A parameter is the variable listed inside the parentheses in the function declaration (it’s a declaration time term).
>>> - An argument is the value that is passed to the function when it is called (it’s a call time term).
>> We declare functions listing their parameters, then call them passing arguments.

5. Default Values
>  Specify the so-called “default” (to use if omitted) value for a parameter in the function declaration, using =.
```javascript
function showMessage(from,text = 'no text given'){
    alert(from = ':' + text);
}
showMessage('Rafael');//Rafael： no text given
//Here "no text given" is a string, but it can be a more complex expression, which is only evaluated and assigned if the parameter is missing. 
```

6. Alternative Default Parameters
> By comparing it with undefined to check if the parameter is passed during the function execution.
```javascript
function showCount(count) {
  // if count is undefined or null, show "unknown"
  alert(count ?? "unknown");
}

showCount(0); // 0
showCount(null); // unknown
showCount(); // unknown
```

7. Returning a Value
>- A function can return a value back into the calling code as the result.
```javascript
function sum(a,b){
    return(a+b);
}
let result = sum(1,2);
alert(result); //3
//The directive return can be in any place of the function. When the execution reaches it, the function stops, and the value is returned to the calling code (assigned to result above).
```

> - There may be many occurrences of return in a single function. For instance:
```javascript
function checkAge(age) {
  if (age >= 18) {
    return true;
  } else {
    return confirm('Do you have permission from your parents?');
  }
}

let age = prompt('How old are you?', 18);

if ( checkAge(age) ) {
  alert( 'Access granted' );
} else {
  alert( 'Access denied' );
}
```
> - It is possible to use return without a value. That causes the function to exit immediately.
> - A function with an empty return or without it returns undefined

8. Functions == Comments
>Functions should be short and do exactly one thing. If that thing is big, maybe it’s worth it to split the function into a few smaller functions. Sometimes following this rule may not be that easy, but it’s definitely a good thing.

>A separate function is not only easier to test and debug – its very existence is a great comment!
