### 2.12 Nullish Coalescing Operator '??'

1. 
> A value is “defined” when it’s neither null nor undefined.
> - a ?? b; 
>> if a is defined, then a;if a is not defined ,then b.
> - ?? returns the first argument if it’s not null/undefined. Otherwise, the second one.
> ```javascript
> //is the same as
> result=(a != null&&a != undefined) ? a:b;

> - The common use case for ?? is to provide a default value.
>> ```javascript
>> let user;
>> alert(user ?? 'Anonymous');//Anonmyous(user is undefined)
>> let user = John;
>> alert(user ?? 'Anonymous');//John(user is defined)

>> We can also use a sequence of ?? to select the first value from a list that isn’t null/undefined.
>> ```javascript
>> let firstname = null;
>> let lastname = null;
>>let nickname = Rafael;
>>alert(firstname ?? lastname ?? nickname ?? 'anonymous'); //Rafael

2. Comparison with ||
- || returns the first truthy value(donot distinguish between false , 0 '' and null/undefined);
- ?? returns the first defined value.

3. Precedence
- The precedence of the ?? operator is the same as ||. 
>That means that, the nullish coalescing operator ?? is evaluated before = and ?, but after most other operations, such as +, *.
> ```javascript
> let height = null;
> let width = null;
> let area = (height ?? 100) * (width * 50);//use parentheses
> alert(area);//5000

4. Not using ?? with && or ||
>Using ?? together with && and || operators is forbidded, unless the precedence is explicitly specified with parentheses.

### 2.13 Loops : While and For

1.  The 'While' Loop
> ```javascript
> let i = 0;
> while(i < 3){ //shows 0, then 1, then 2
> alert(i);
> i++;    
> }

> - A single execution of the loop body is called an iteration. The loop in the example above makes three iterations.
> - While the condition is truthy, the code from the loop body is executed; otherwise, while the condition is falsy, which is, when the codition is false , 0 '' and null/undefined, the loop will stop.
> - Curly braces {}are not required for a single-line body
>> ```javascript
>> let i = 3;
>> while(i) alert(i--);

2. The 'Do...While' Loop
> ```javascript
> let i = 0;
> do {
> alert(i);
> i++;
> } while(i<3);

3. The 'for' Loop
>  ```javascript
> for(let i=0 ; i<3; i++){
> alert(i);
> }

1. The 'for' statment part-by part
>- begin	let i = 0	Executes once upon entering the loop.
>- condition	i < 3	Checked before every loop iteration. If false, the loop stops.
>- body	alert(i)	Runs again and again while the condition is truthy.
>- step	i++	Executes after the body on each iteration.

2. Inline Variable Declaration
>The “counter” variable is declared right in the loop. This is called an “inline” variable declaration. Such variables are visible only inside the loop.
> ```javascript
> for(let i=0 ; i<3; i++){
> alert(i);
> }
> alert(i); //error, no such value

3. Skiping parts
> Any part of for can be skipped, while the two for semicolons ; must be present.
> ```javascript
> let i = 0;
> for(;i<3;i++){
> alert(i);
> }

> ```javascript
> let i = 0;
> for(;i<3;){
> alert(i++);
> }

4. Breaking the Loop
> The special break directive can be used anytime  to force the loop exit.
> ```javascript
> let sum = 0;
> while(true);{
> let value = +prompt('enter a number','')
> if (!value)break;
> sum += value;
> }
> alert('sum:' +sum)
>//he break directive is activated at the line (*) if the user enters an empty line or cancels the input. It stops the loop immediately, passing control to the first line after the loop. Namely, alert.

5. Continue to The Next Iteration
>The continue directive stops the current iteration and forces the loop to start a new one (if the condition allows).
> ```javascript
> for(let i=0; i<10 ; i++){
> if(i%2==0) continue;
> alert(i); //1, then 3, then 5, then 7, then 9
> }
>//For even values of i, the continue directive stops executing the body and passes control to the next iteration of for (with the next number). So the alert is only called for odd values.

6. Labels for Break/Continue
> A label is an identifier with a colon before a loop: the break 'labelname' statment in the loop below breaks out to the label.

> ```javascript
> outer: 
> for(let i=0 ; i<3 ; i++){
> for(let j=0 ; j<3 ; j++) {
>  let input = prompt=('value at coords(${i},${j})','')
>   if(!input) break outer;
>  }
> }
> alert('done');

> In the code above, break outer looks upwards for the label named outer and breaks out of that loop.
